# Hi, I'm Josh 👋

I build machine learning systems with a focus on **healthcare AI**, **explainability**, and **production deployment**.

## 🛒 Featured Project: Next Basket Predictor

A dual-domain AI app that predicts what a customer will buy next — in either a **grocery store** or a **pharmacy**.

**Highlights:**
- Custom **TLFIG-Transformer** (trend + fuzzy granulation) for next-basket prediction
- **GPBoost** for user/pharmacy random effects modeling
- LLM-powered natural language input (Groq + Pollinations fallback)
- 6-step Streamlit UI with persistent cart, theme toggle, and PDF export
- Trained on Instacart (3.4M orders) + NHS Scotland (1.5M prescriptions)

**Stack:** Python · PyTorch · Streamlit · GPBoost · Groq API · pandas · ReportLab

## 🫀 Featured Project: Heart Disease Risk Prediction

A deployed ML web app for predicting heart disease risk using CatBoost + XGBoost on 253,680 BRFSS 2015 records.

**Highlights:**
- Calibrated gradient boosting models (ROC-AUC 0.85, PR-AUC 0.37, Brier 0.07)
- LLM-assisted natural language input with multi-provider fallback
- Dual SHAP explainability (CatBoost + XGBoost)
- Interactive visualizations + PDF report export
- Light/dark theme support

**Stack:** Python · Streamlit · CatBoost · XGBoost · SHAP · Gemini API · Plotly · fpdf2
